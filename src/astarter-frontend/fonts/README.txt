Astarter multilingual screen fonts

UI: Inter Variable (Latin, Greek, Cyrillic and Vietnamese).
Chinese: Noto Sans SC. Japanese: Noto Sans JP. Korean: Noto Sans KR.
Fixed-width identifiers and existing terminal metrics: IBM Plex Mono, weights 400/500/600/700.
Font fallback uses the operating system; no system font files are redistributed.

Distribution: SIL Open Font License 1.1. Keep each copyright notice and OFL text with the fonts.
The license permits commercial use and embedding with software. The font software must not
be sold on its own. Reserved font names and redistribution conditions continue to apply.
These are licensed copyrighted fonts, not public-domain or copyright-free assets.

The Google Fonts WOFF2 subsets are copied without modification. manifest.json records each
versioned download URL, byte size, SHA-256 and Unicode range. faces.css declares those ranges,
so browsers fetch only subsets needed by the current text and active regional font.
All runtime font requests are same-origin; Google Fonts is not contacted by the application.
The old Manrope and two old Plex files remain as prior local assets and are not referenced
by the new shared font sheet.
