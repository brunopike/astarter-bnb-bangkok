# 后端恢复边界

- 首先固定来源版本、目标、actor、有效期和原回执。只读查询旧请求的结果，不因未知响应生成新的逻辑请求。
- PRIVATE、PUBLIC、研究和原生执行的 schema/profile 分开校验，不借同一 Neon 项目或同名 role 推断权限已验证。
- UNKNOWN 不是失败退款或自动重试。已经发送、可能提交或可能产生供应商责任的操作保留原责任；只有已证未发送的预留才能按合同释放。
- R3 的本地 v3 支持不代表 Neon v3 已验。原 schema2 二进制会拒绝 schema3，不能在已提交迁移后简单回退旧服务冒充恢复。
- 恢复前核预算、期限、当前 catalog、权限、owner lease 和 source hash。过期/已消耗的操作不能删除 attempt、换库、换 UUID、延长旧窗口或重置额度后重跑。
- 保留数据库与 WAL/SHM、失败日志和原 receipts；它们属于受保护的运行资料，不上传普通仓库。不要通过删除历史、预算或失败测试制造验收通过。

目前没有通过本次整理执行任何迁移、回退、云恢复或生产切换。[当前状态](../current-status.md) 列出仍未通过的门槛。
